# EE 独立性重构：流程、角色与留痕索引

本目录是"把从 Langfuse 商业版改编而来的 EE 代码替换为独立实现"这一工作的过程记录。目标：让 `LICENSE-EE` ANNEX A 列出的文件在版权上真正属于我们自己，从而可以直接标注为自有代码，而不是"改自衍生作品"。

## 1. 角色与命名

| 名称 | 角色 | 是否接触过原实现 | 职责 |
| --- | --- | --- | --- |
| **Select DB** | 主控方（`看过代码`的一方） | **是** | 圈定批次边界；撰写行为规格；编写与复核特征测试；执行变异测试与四级门禁；决定是否换入；撰写各批次记录与最终报告 |
| **Zhang Mo** | 净室实现者 | **否** | 仅依据行为规格与验收测试进行实现；不打开目标文件本体、其 git 历史/diff，也不对含目标文件的目录做检索；须交回声明与实际用过的检索命令 |

规则：
- **看过原实现的人不能充当实现者**，因此 Select DB 不参与编码；实现者也不得事后去读原实现来"对照"。
- 实现者的输入只有三样：`spec.md`、验收测试、规格列出的接口清单。规格中只描述**行为**，不含原实现正文、不引用行号。
- 编码在**隔离上下文**中完成（每次实现会话不继承任何已阅原实现的上下文），并逐批次交回第一人称声明；声明与披露写入该批次的 `record.md`。

> **命名沿革**：批次 0 / 批次 1 的文档（`00-support-or-upgrade-page/`、`01-audit-logs/`）早于本命名约定，使用中性措辞"独立执行上下文""主控会话"。其内容、责任归属与上述映射一致（"独立执行上下文"即 **Zhang Mo**，"主控会话"即 **Select DB**），**不做事后改写**——证据文件写定后不回改，是留痕可信度的一部分。

## 2. 净室流程（每批次固定执行）

1. **圈边界**：按 `LICENSE-EE` ANNEX A 的逐条路径确定本批次文件清单。
2. **规格**：Select DB 读原实现并撰写 `spec.md`——导出签名与类型、校验顺序、精确状态码与错误串、每张表的读写/过滤/投影/排序、副作用、i18n 结论、特征化用例清单、Open questions。
3. **特征测试**：先在**原实现**上跑绿，证明锁的是"当前真实行为"而非"设想的行为"；文案可改的批次，断言必须功能导向。
4. **变异测试**：故意改坏 1–2 处行为，必须**恰好**命中预期的那几条断言、其余仍绿——否则"全绿"没有意义。
5. **隔离实现**（Zhang Mo）：换入，原位替换。
6. **四级门禁**（Select DB，工具 `~/SelectDB/litefuse-local/bin/ee-refactor-check.sh`）：
   - **L0 静态**：prettier（改动文件）、web/worker tsgo、EE 边界（静态 MIT→EE 必须为 0）、i18n；
   - **L1 行为**：特征测试改后仍绿；
   - **L2 批次回归**：重建 + 重启（服务必须由**被测 worktree**提供）+ smoke + 本族 servertest，与**冻结基线做集合等价比对**；
   - **L3 高风险 e2e**：仅 SSO / billing 等文件族。
7. **相似度自查**（`bin/ee-similarity-report.mjs` → `similarity.md`）：EE-only 共享实质行、≥2 连续行共享块、token 5-gram Jaccard，**残余逐条给理由**。
8. **留痕与提交**：每批次一个提交，含 `spec.md` / `record.md` / `similarity.md` / `verification.md`。

失败回退：L0 红直接修；L1 红且判定为实现缺陷 → `git checkout -- <文件>` 重写（一文件一提交，回退粒度就是文件）；L2 红 → 整批暂停定位；L3 红 → 该文件暂缓单独评估。

## 4. 证据分三层（各自能证明什么）

| 层 | 载体 | 能证明 | 不能证明 |
| --- | --- | --- | --- |
| **过程（最强）** | `record.md` | 实现者的可见输入、禁令、声明原文、披露的意外暴露、实际检索命令 → 支撑"独立创作"的主张 | 依赖披露质量；无法复核实现者的全部操作 |
| **行为** | 特征测试 + 变异测试 + L0/L2 集合等价比对 | 换入的实现**行为等价** | 与原创性无直接关系 |
| **文本（否证性）** | `similarity.md` 三项度量 | 发现**残留拷贝块** | 不能证明独立——独立实现会自然收敛到相同写法（批次 0 的居中方式即为一例：独立实现比原实现**更像**上游） |

**边界（须与结论一并陈述）**：
- 净室只解决"衍生作品"一条路径；对不重写的文件，出路只有 **取得授权 / 净室替换 / 移除**，并把"适用许可 + 依据"逐文件登记在 `LICENSE-EE-PROVENANCE.md`。
- 相似度工具只覆盖**上游 Langfuse EE 树**；不覆盖第三方库或其它来源。
- 结论口径：**"已有证据足以支撑独立创作的主张"**，而非"已证明原创"。本目录的留痕是将来正式法律审查的输入。
