# 05 · 内部参考文档清单与去向

本项目在迁移期间积累了 **15 篇中文内部规范/工作笔记**。它们**有意不随本仓库提交**（其中含实测数字、本地环境细节与内部登录信息，不适合进入公开仓库）。

- 在当前 Windows 开发机上，它们位于：`D:\SelectDB\litefuse-master\handover-reference\`
- 换到 macOS 新机器时，这些文件**必须通过 git 之外的方式带过去**（手工拷贝 / 安全传输），拷到任意位置均可，只要 15 个文件保持在同一目录。
- 该目录下另外有一份 `README.md`（**阅读顺序地图**），与这 15 篇同级存放；它按阶段给出建议阅读顺序，并逐篇说明"什么时候该翻它"。要读原始规范前，先看这份地图。

| `改造方案-上游架构+litefuse命名+Doris存储.md` | 方法论：三层三分法、改名字典的三条规则、存储适配层的接缝在哪。 |
